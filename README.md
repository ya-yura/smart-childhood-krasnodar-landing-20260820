# «Умное детство» — лендинг центра развития в Краснодаре

Mobile-first лендинг с маршрутом родителя: возраст → задача → направление → следующий шаг. Проект собран на React + vinext и подготовлен к сборке через Sites.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run build
npm run lint
npm test
```

## Что реализовано

- первый экран с подтверждёнными данными: Краснодар, рейтинг 5,0 в 2ГИС и 37 оценок;
- интерактивный квиз на 4 шага с предварительной рекомендацией;
- карточки пяти направлений: подготовка к школе, Монтессори, скорочтение, творчество и продлёнка;
- структурированная заявка в WhatsApp на номер `+7 928 849-69-78`;
- форма с защитой от повторной отправки, состоянием успеха и согласием на обработку персональных данных;
- мобильная плавающая кнопка WhatsApp;
- FAQ, маршрут выбора в 3 шага и базовые события аналитики: `quiz_view`, `quiz_start`, `quiz_complete`, `whatsapp_click`, `form_submit`, `trial_click`;
- мета-title, description и keywords для поисковых запросов про подготовку к школе, Монтессори и продлёнку в Краснодаре;
- адаптивность для 320–430 px и поведение `prefers-reduced-motion`.

## Материалы и подтверждения перед релизом

В доступной папке не было материалов центра. Hero-визуал — оригинальная editorial-иллюстрация атмосферы, а не фотография реального пространства. Перед клиентским запуском её нужно заменить на согласованную фотографию центра или занятия в `public/hero-atmosphere.webp`.

Также перед публикацией нужно подтвердить и при необходимости добавить: точный адрес, режим работы, актуальное расписание, стоимость, условия пробного занятия, реальные отзывы, фото помещений, информацию о педагогах, условия продлёнки и текст политики конфиденциальности. Пока сайт использует только подтверждённые сведения из брифа и нейтральные формулировки без обещаний результата.

## Структура

- `app/page.tsx` — страница, квиз, формы и интерактивные состояния;
- `app/globals.css` — адаптивная визуальная система;
- `app/layout.tsx` — SEO-метаданные;
- `public/hero-atmosphere.webp` — editorial hero-визуал;
- `.openai/hosting.json` — метаданные Sites.
